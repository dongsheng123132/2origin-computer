# 我的总判断

从最高层看，未来真正发生的，不是“AI 变得越来越像人”，而是：

> **计算机的中心将从“机器、App、账号、模型”，逐渐迁移到“一个持续存在的主体”。**

过去几十年，计算系统的中心不断变化：

```text
大型机时代：中心是一台机器
PC 时代：中心是一个用户和本地文件
互联网时代：中心是网站和账户
手机时代：中心是 App 和平台
大模型时代：中心正在变成模型和对话窗口
未来：中心应当重新回到一个真实的人
```

这里存在两条完全不同的未来路径。

一种是**平台封建化**：

```text
苹果拥有你的设备上下文
Google 拥有你的手机上下文
某个模型公司拥有你的记忆
某个 Agent 平台拥有你的工作历史
机器人厂商拥有你的身体能力
```

你看似拥有很多 AI，实际上只是把自己的记忆、能力和生活分别寄存在不同公司的领地里。

另一种是**主体中心化**：

```text
记忆属于人
设备属于人
权限属于人
任务属于人
行动历史属于人
模型只是临时参与者
Agent 只是受委托者
机器人只是可治理的身体
```

我认为，真正值得推动的是第二种。

---

# 一、未来人与 AI 的最佳关系，不是主人与奴隶，也不是 AI 取代人

我会把理想状态描述为：

# **可退出、可纠正、可审计的宪法化共生**

“共生”不是让 AI 永远服从人的每一个即时冲动，也不是让 AI 成为一个无所不能的主人。

而是：

* 人提供价值、意义、关系和最终主权；
* AI 提供记忆、模拟、推理、执行和协调；
* 设备和机器人提供感知与行动；
* 一套长期规则决定谁可以在什么时候做什么；
* 所有重要判断都可以被质疑；
* 所有重要行动都可以追溯；
* 用户可以换模型、停用模块、删除记忆、收回授权。

Licklider 在 1960 年设想的人机共生，核心就不是机器简单替代人，而是人与计算机在问题形成、实时思考和复杂决策中形成互补关系。具身认知和延展心智理论则进一步指出，人的认知并不只局限在大脑内部，也依赖身体、环境和外部工具。([斯坦福哲學百科全書][1])

所以未来的 AI，不应只是“一个聊天机器人”，而更接近：

> **人的外部记忆、模拟器、执行机构、教练、秘书和可扩展身体。**

但它必须始终是**人的扩展**，而不是人的所有者。

---

# 二、最好的 AI 不只是“替你做事”，而是扩大你的主体性

判断一个 AI 是否真的帮助人，不能只看它完成了多少任务。

更重要的是看：

```text
它是否让你更清楚自己在做什么？
它是否保留了你的选择能力？
它是否可以向你解释和提出异议？
你是否可以纠正它对你的理解？
你能否换掉它而不失去记忆和工作？
你能否撤销它的权力？
你能否彻底删除它掌握的内容？
它是在增强你的判断力，还是让你逐渐丧失判断力？
```

因此未来 AI 应支持不同的关系模式：

| 模式 | AI 的角色            |
| -- | ----------------- |
| 观察 | 只记录，不主动判断         |
| 建议 | 给出建议，人自己执行        |
| 协作 | 人和 AI 一起完成        |
| 教练 | AI 帮助人学会，而不是直接代劳  |
| 委托 | AI 在明确范围内自主完成     |
| 守护 | 在风险、健康、安全等情况下主动提醒 |
| 代理 | 在法律、工作或商业范围内代表人行动 |

最佳系统不是永远开“全自动”。

而是让人可以决定：

> **这件事我要自己做、和 AI 一起做、让 AI 教我做，还是完整委托给 AI。**

NIST 的 AI 风险框架也明确区分了从完全人工到高度自主的不同人机配置，并指出这些边界需要被清楚定义。([NIST 出版系列][2])

所以正确目标不是简单的 “human in the loop”。

而是：

# **Human in command**

人不需要每一步都点击确认，但始终拥有规则制定权、撤销权和最终治理权。

---

# 三、今天到未来，大致会经历六个阶段

## 第一阶段：AI 是工具

```text
人知道目标
人拆解任务
人提供全部上下文
AI 生成一段答案
```

典型形态是聊天、写作、图片生成。

这个阶段，人仍然承担绝大部分规划和状态管理。

---

## 第二阶段：AI 是副驾驶

```text
AI 看见当前文件
AI 能提出修改
人逐步确认
```

典型形态是代码助手、Office 助手、设计助手。

AI 开始理解局部环境，但仍然没有持续主体和长期工作状态。

---

## 第三阶段：AI 是 Agent

```text
目标
→ 规划
→ 调用工具
→ 执行多个步骤
→ 生成结果
```

DSH、Claude Code、Codex、各种 Harness 都在这一层。

截至 2026 年 8 月，MCP 已经在标准化资源、Prompt、工具和持久任务；A2A 在标准化 Agent 之间的 Task、Message、Artifact 和状态更新；Android 则明确从“App 启动器”转向“任务编排的智能系统”，并用 AppFunctions 让 App 成为端侧工具提供者。([Model Context Protocol][3])

这是今天最火的阶段。

但是这个阶段的中心仍然往往是：

```text
一个 Session
一个 Agent
一个 Harness
一个模型
一次任务
```

---

## 第四阶段：AI 成为个人持续运行时

这一阶段，AI 不再从每次 Prompt 开始。

它知道：

```text
这个人是谁
过去发生过什么
现在正在做什么
有哪些未完成承诺
有哪些设备在线
哪些数据可以使用
哪些模型可以调用
哪些事情必须由本人批准
```

此时真正的中心不再是 Agent，而是人的连续性。

行业已经开始出现“可携带 Agent 记忆”“开放记忆协议”“Agent 身份协议”等项目和草案，这说明记忆可移植性、Agent 身份和委托权力已经成为新的基础设施问题；但这些仍处于早期探索期，尚未形成覆盖个人长期生活、设备、行动、遗忘和责任的统一标准。([arXiv][4])

我认为，我们今天正处于：

> **第三阶段向第四阶段跨越的入口。**

---

## 第五阶段：AI 获得分布式身体

```text
手机
电脑
录音卡
眼镜
手表
车辆
摄像头
机器人
脑机接口
```

都不再是独立 App 或独立设备，而是围绕某个主体组织起来的感官、计算节点和行动器官。

AI 不只是调用网页 API，而是真正进入人的生活环境。

这时候必须区分：

```text
大模型负责高层理解和规划
设备负责局部计算
机器人负责实时控制和安全反射
人负责价值和最终授权
```

---

## 第六阶段：个人 AI 进入社会

未来不会只有“我和我的 AI”。

而会出现：

```text
我的 AI
你的 AI
公司的 AI
医院的 AI
机器人的 AI
政府机构的 AI
```

它们会彼此：

* 协商日程；
* 分配工作；
* 签订承诺；
* 交换有限信息；
* 代表不同主体报价；
* 请求许可；
* 验证交付；
* 处理争议。

那时最难的已经不是模型推理。

而是：

> **不同主体的 AI 如何合法地代表谁、承诺什么、披露什么、承担什么责任。**

---

# 四、从哲学上看，未来需要重构八个基本概念

传统计算机科学的核心对象是：

```text
进程
文件
内存
网络
设备
用户账户
```

未来个人智能系统的核心对象会变成：

```text
主体
事实
意图
授权
行动
责任
记忆
注意力
```

这八个概念，就是最值得重新定义的地方。

---

# 五、你现有几套东西，实际上已经占据了四个非常关键的位置

## 1. 本象：存在论与认识论

它回答：

> **世界现在是什么样子？系统凭什么这样认为？**

它不应该只是数据格式，而应该区分：

```text
设备直接观察
用户确认
确定性计算
模型推断
未来预测
存在争议
已经被替代
```

本象真正有价值的地方，不是“压缩上下文”，而是：

> **让事实、推断和模型视图不再混在一起。**

这属于认识论层。

---

## 2. 本境：时间、记忆与身份连续性

它回答：

> **哪些过去应该继续影响未来？**

本境不只是向量数据库，而应该管理：

```text
经历
事实
偏好
技能
失败
关系
承诺
情绪趋势
遗忘
修正
封存
删除
```

这属于时间哲学和身份连续性层。

---

## 3. 影核：行动哲学

影核之所以是一个很成功的想法，是因为它找到了真正的“不变量”：

> **界面会变化，但动作本身不应该变化。**

同一个动作可以投影为：

```text
GUI 按钮
CLI 命令
MCP Tool
Android AppFunction
iOS App Intent
机器人 Action
语音命令
```

但是动作本身的：

```text
目的
输入
后果
风险
权限
验证
回滚
证据
```

应当只有一个源。

影核解决的是“意图如何成为现实变化”。

这属于行动理论和因果层。

---

## 4. 任务护照：目的论与承诺连续性

它回答：

> **一项工作在换模型、换设备、换 Agent、换时间以后，怎样仍然是同一件工作？**

任务护照保护的是：

```text
目标
为什么要做
验收条件
当前状态
已经证实的事实
失败尝试
环境
产物
检查点
下一步
责任人
```

这属于目的论和承诺层。

---

## 5. 本源计算机：完整发行版

它不是协议，而是：

> **把人的手机、电脑、传感器、记忆、工作和各种 AI 组合起来的参考系统。**

因此你的体系并不是几个随机想法。

从高维度看，它们已经分别占据：

```text
世界是什么
过去留下什么
如何改变世界
目标如何持续
整个系统如何交付
```

这是很完整的一条主线。

---

# 六、但还缺四个极其重要的层

## 第一缺口：主体与主权

目前最根本、最值得定义的，是：

> **一个 AI 到底代表谁？**

不能只定义 Agent ID。

需要定义：

```text
主体是谁
这个主体可以是人、机器狗、团队还是企业
谁拥有最终治理权
哪些设备属于这个主体
哪些记忆属于这个主体
某个 Agent 是自己行动，还是代表别人行动
授权能否继续委托
模型更换以后主体如何保持连续
```

今天的 OAuth、工作负载身份、Agent Identity 草案主要解决认证和权限，但“主体的长期连续性、价值边界和跨设备主权”仍没有一个成熟的通用答案。NIST 在 2026 年启动 AI Agent 标准计划，也明确把 Agent 身份、授权、安全互操作作为新的标准化前沿。([NIST][5])

这是你现有体系中最明显缺的一块。

---

## 第二缺口：个人宪法与可执行授权

未来 AI 不应该只拿到：

```text
允许读文件
允许发消息
允许用摄像头
```

而应该获得：

```text
谁授权
为了什么目的
允许访问哪些范围
可以持续多久
最大花费多少
能否联网
能否转交其他 Agent
什么情况需要再次确认
什么事情绝对禁止
出现冲突时听谁的
```

它更像一部可执行的个人宪法。

例如：

```text
家庭录音不得交给云端模型
任何付款都必须由本人指纹确认
低风险可撤销日程可以自动创建
工作 Realm 不得访问私人情感记录
连续工作超过四小时，AI可以建议休息，但不能强制终止
```

这会成为人与 AI 关系的真正政治基础。

---

## 第三缺口：注意力协议

这是我认为最容易被整个行业忽略、但非常可能成为“下一次影核”的东西。

未来最大稀缺资源不只是算力，而是：

# **人的注意力**

当 AI、手机、汽车、眼镜、机器人、家庭设备都能主动找你时，谁有权打断你？

需要定义：

```text
为什么现在必须提醒
如果不提醒会发生什么
紧急程度是多少
这件事多久后失效
可以在哪个界面提醒
是否允许重复提醒
用户当前是否可被打断
是否应先由另一个 AI 处理
```

一个通知不应该只有：

```text
title
body
```

而应该包含：

```yaml
reason: 构建失败且阻塞发布
urgency: high
expires_in: 20m
interruption_cost: medium
can_delegate: true
suggested_action: 允许另一台 Windows 测试机接手
why_now: 当前发布窗口将在 18:00 关闭
```

如果没有注意力治理，未来 AI 不会成为助手，而会成为比今天广告推送更强的行为操纵机器。

我没有在目前主流的 MCP、A2A、AppFunctions 或 Agent 身份标准中看到一个成熟的、跨系统的“注意力与打断权”标准。这是基于这些标准公开职责范围作出的判断。([Model Context Protocol][3])

---

## 第四缺口：多主体关系与承诺

当个人 AI 开始代表不同人互动时，需要的不只是 Agent-to-Agent Message。

需要定义：

```text
谁向谁提出了什么
是否代表本人
有多大承诺权限
是否涉及第三方数据
对方是否同意
承诺何时成立
如何撤销
如何验证完成
失败由谁承担
```

例如：

> 我的 AI 可以和供应商 AI 协商会议时间，但不能代表我签署采购合同。

或者：

> 机器狗可以接受家庭成员让它巡逻的任务，但不能允许陌生人读取摄像头。

A2A 已经能传输 Task、Message 和 Artifact，但它并不替主体解决社会承诺、代理边界、共同同意和责任归属。([A2A Protocol][6])

这会是未来 AI 社会的“合同法”和“外交协议”。

---

# 七、还需要发明的三个长期层

## 1. 经验如何变成技能

未来 AI 不应只是把所有经历存进记忆。

它还应把经过验证的经验提炼成技能：

```text
经历
→ 发现重复模式
→ 形成候选技能
→ 在沙箱中测试
→ 运行回归测试
→ 人或审计 Agent 批准
→ 成为正式技能
→ 持续监控
→ 失败时回滚
```

这其实是未来智能系统的“神经可塑性协议”。

否则系统会有两个极端：

* 永远不会成长；
* 不受控制地修改自己。

正确的是：

> **可验证、可版本化、可回滚的成长。**

---

## 2. AI 的新陈代谢

未来系统需要同时分配：

```text
算力
电量
模型费用
网络流量
存储空间
隐私暴露
人的注意力
社会风险
```

这就是 AI 系统的“代谢调度”。

例如：

```text
原始录音不允许出本地
→ 把模型移动到录音所在设备

任务不紧急
→ 等家庭电脑空闲后执行

手机电量低
→ 暂停视觉分析

云端预算不足
→ 切换本地小模型

用户正在开车
→ 将复杂确认延后
```

传统操作系统只调度 CPU 和内存。

未来个人智能内核还要调度：

> **隐私、金钱、注意力和风险。**

---

## 3. 死亡、继承与数字遗产

如果一个系统真的记录一个人的长期生活，就必须回答：

```text
人死亡以后数据怎么办
谁可以继承
哪些内容必须销毁
AI 是否可以继续模拟这个人
亲属是否有权访问
过去承诺如何处理
机器主体如何转移所有权
脑机和健康数据如何封存
```

这不是遥远问题。

一旦做长期记忆，就必须从第一天留下生命周期接口。

UNESCO 在 2025 年通过的神经技术伦理建议已经把自由、知情决定、精神隐私、人格身份和心理连续性列为重要原则。未来脑机接口接入个人 AI 后，这些问题会直接进入系统设计。([聯合國教科文組織][7])

---

# 八、未来 AI 系统需要“权力分立”，而不是一个超级 Agent

我越来越确信，未来正确架构不是：

```text
一个超级模型
拥有全部记忆
拥有全部工具
拥有全部权限
自己判断
自己执行
自己说执行成功
```

这相当于：

> 一个人同时当侦察员、法官、政府、军队和审计机构。

正确架构应该有类似“权力分立”的结构：

```text
观察者
负责采集事实，但不能随意行动

记忆者
负责保存和检索，但不决定目标

解释者
提出推断，但必须标明置信度

规划者
提出方案，但不能直接越权执行

批评者
寻找风险、冲突和替代方案

宪法与策略层
决定是否有权执行

执行者
按批准的动作工作

验证者
检查行动是否真的成功

审计者
保存责任和证据
```

这些角色可以由不同模型、规则或插件承担。

这样即使一个模型犯错，也不会直接控制全部系统。

这是未来“AI 操作系统”最需要的政治哲学。

---

# 九、影核为什么是一个正确的发明方法

影核的价值不只是协议内容。

它揭示了一种发明未来协议的方法：

# **寻找变化背后的不变量**

界面不断变化：

```text
GUI
CLI
语音
手机
眼镜
机器人
脑机
```

但“创建日程”这个动作不应变化。

因此：

```text
动作是源
界面是投影
```

沿用这个方法，还可以找到其他不变量：

| 不变量 | 外部可变的东西            |
| --- | ------------------ |
| 主体  | 模型、账户、设备           |
| 事实  | 摘要、视图、Prompt       |
| 意图  | Agent、Harness、执行路径 |
| 授权  | Token、平台权限、设备      |
| 动作  | GUI、CLI、机器人指令      |
| 责任  | 日志格式、厂商、模型         |
| 记忆  | 数据库、Embedding、模型   |
| 注意力 | 手机、眼镜、手表、语音        |

未来真正有价值的协议，不是围绕今天某个产品，而是定义这些跨时代的不变量。

---

# 十、我建议把整个系统建立在八条“守恒律”上

## 1. 主体守恒

换模型、换手机、换服务器，主体不能变成另一个人。

## 2. 意图守恒

任务跨 Agent 接力时，目标和验收条件不能悄悄改变。

## 3. 事实守恒

事实经过摘要、压缩和模型加工后，仍必须能追溯来源。

## 4. 权限单调

委托链中的权限只能缩小，不能在没有新授权时扩大。

## 5. 行动同源

同一动作在 GUI、CLI、手机和机器人上的语义保持一致。

## 6. 责任守恒

每次真实世界变化都必须知道请求者、授权者、执行者和结果。

## 7. 遗忘传播

删除原始数据时，所有派生记忆、索引和推断都必须被定位并处理。

## 8. 注意力有界

任何 AI 都无权无限制占用人的注意力。

这八条可以直接变成：

* 架构原则；
* Schema 约束；
* 回归测试；
* 插件兼容测试；
* 项目宣言。

# 最后的“上帝视角”判断

过去的计算机，是围绕机器组织的。

今天的 AI，是围绕模型组织的。

未来正确的智能基础设施，应该围绕：

# **一个持续生活、拥有关系、承担责任、能够改变和有权遗忘的人。**

AI 最终不是人的替代品。

它更像人的：

* 外部记忆；
* 第二注意系统；
* 模拟与反思伙伴；
* 可委托的执行机构；
* 延伸到世界中的身体；
* 由个人宪法约束的智能制度。

所以真正值得发明的，不是“更像人的 AI”。

而是：

> **一种让任何 AI 都能合法、安全、可替换地进入一个人的生活，同时又永远无法夺走这个人的主体性、记忆主权和退出权的基础制度。**

从这个角度看，影核确实是一个很好的开端。

它找到的是“行动的不变量”。

下一步需要继续找到并定义：

> **主体的不变量、事实的不变量、意图的不变量、授权的不变量、责任的不变量、注意力的不变量，以及遗忘的权利。**

这些东西一旦被定义清楚，才可能成为未来 AI 世界真正类似 Linux、POSIX 或互联网协议那样的基础。
