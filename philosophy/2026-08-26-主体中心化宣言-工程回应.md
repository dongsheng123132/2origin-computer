## 0. 一句话定性

宣言是合格的北极星，不是路线图：它抓对了「可退出/可纠正/可审计」这组工程指标，
但只有立法没有执法与激励——违宪谁裁决、撤销的真实代价谁定价、现有平台凭什么加入，均未回答。
按本体系自己的规矩（名字是免费的、判据是贵的），本文只收判据撑得住的部分。

## 1. 保留的三个判断（值得长期挂在墙上）

1. **持续主体是北极星**：计算中心从 Session/模型迁到可持续、可迁移的主体状态；
   竞争定义不是「谁的模型好」，是「连续性归谁所有」。这与本体系已验证的
   「state survives / model replaceable」（ShadowWork bench v0.4）同向。
2. **Human in command 取代 human in loop**：可退出/可纠正/可审计是工程指标不是口号，
   可直接落成撤权、冲突拒绝、证据链、删除结算等测试。uenv 的 Confirm 档 +
   影核的人工确认档已是局部实例。
3. **「寻找变化背后的不变量」是已被验证过一次的协议生成方法**（影核即产物），
   可复用，但每次使用都要过 §3 的准入判据。

宣言把「本境」当成时间/记忆/身份连续性层。**错。** 现行裁决（NAMING-DECISION §1）：

**本轮两个窄化 candidate：**
1. 高风险动作跨层授权闭环
2. 学堂的技能晋升/回归/回滚生命周期

六个宣言名一律不转正。

## 4. 两个 candidate 的最小实验与证伪条件

### C1 高风险动作跨层授权闭环

- **最小实验**：选一个真实高风险动作（影核/U-King 的管理员级写操作），授权闸携带
  `subject / purpose / scope / expires / revocation / uenv_fingerprint`，
  用现有 proof 家族产出四个确定性判例：
  允许 · 拒绝 · 撤权后拒绝 · 陈旧环境指纹拒绝（A 机批准 B 机重放必须失败）。
- **复用资产**：policy-waiver（scope/有效期/次数绑定）、principal-binding（代表谁）、
  uenv fingerprint（环境新鲜度）、影核 risk-tier + approval。
- **证伪条件**：若四个判例中任何一个无法确定性判定（如环境指纹在批准与执行间合法变化导致
  无法区分「陈旧」与「正常演进」），则该缺口退回观察名单，不立项。
- **成功后的去向**：才考虑占 RFC 号。产品入口叫「安全执行保护」，不发《个人宪法协议》。

### C2 学堂技能晋升生命周期

- **最小实验**：给 learn 补三件套：沙箱回归（candidate 在受控任务上重跑 N 次）、
  版本提升履历（谁/凭什么证据升到 verified）、失败回滚（verified 降回 candidate 的触发器）。
- **复用资产**：learn(candidate→verified)、capability receipt（证明实际加载的是哪份 skill）、
  ShadowWork bench（现成的对照实验装置）。
- **证伪条件**：若晋升判据只能靠人工裁定、无法用 bench 自动判定，则承认这条线的
  自动化前提不成立，降级为纯人工流程文档。

## 5. 明确不收的（防第二真相源）

- 原文的缩写复刻或「优化版宣言」——原文已存 incoming/，永不改写；
- 新 schema、新协议字段、新官方层级、把「八条守恒律」当规范——它们目前是
  **待验证的不变量**，其中意图/事实/行动三条有工程对应物，主体/权限/责任三条只有零件，
  遗忘传播有最小证明器，注意力有界完全空白（判定依据见本境协议仓 docs/14 §四）;
- 六阶段未来史、行业趋势断言（引用核查结论：五条引用全部真实存在，但 MCP Tasks 是
  experimental、arXiv 2605.11032 是单作者预印本，均不足以支撑「行业已成共识」级表述）;
- 架构真相表的第二份拷贝——部件归位一律引用 NAMING-DECISION §1，不在本文复制。

## 6. 本境协议（uenv）对外一句话（优先级定死）

> **本境协议首先是 2Origin 的 Machine Profile：把「这台机器有什么、能不能跑」变成可复核的环境事实；
> 因此它可作为认识论账本的环境域实例，并可在未来授权闸中提供策略证据——但它本身不是记忆层、个人宪法或远程证明机构。**

Machine Profile 是身份；环境域实例是架构解释；policy evidence provider 是未来用途，用「可」不用「已是」。
